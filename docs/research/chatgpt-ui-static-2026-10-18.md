ㅆ나요률, 실패와 재시도.
- 새 메시지·과거 메시지 로딩·최신 메시지로 복귀·재연결.
- 저장됐지만 전달은 확인되지 않은 상태와 전송 실패 상태의 구분.
- 생성된 작업 카드, 작업 열기, 컴퓨터 환경 표시, 통화 종료 결과.
- SMS·RCS·iMessage·ChatGPT 등 발송 채널을 표시하는 문구. 이 계정의 채널 연결 여부는 미확인.

특히 “저장됨”과 “전달됨”을 같은 상태로 취급하지 않는다. 전달 미확인 시 재전송 전에 대화를 확인하라는 안내가 있다. [E15, E16]

결과물 패널은 로딩·빈 상태·조회 실패를 구분하고 문서, 스프레드시트, 프레젠테이션, 이미지, 웹사이트, 파일 등을 표현한다. 코드 작업에서는 PR/MR·워크트리 관련 항목도 있다. dot 화면에서 현재 어떤 결과물 종류가 노출되는지는 런타임 확인이 필요하다. [E22]

### 온보딩 구성

`OrbitPage`가 내보내지는 `page-3f5e759fa37f.js`는 다음 단계와 분기를 포함한다. 아래는 단계 후보의 기능별 목록이며 모든 계정에 고정된 단일 순서를 뜻하지 않는다.

1. dot 소개와 생성 시작.
2. 클라우드 컴퓨터와 사용자 로컬 컴퓨터 중 작업할 환경 선택.
3. 색상·캐릭터 및 애니메이션 외형 선택.
4. Google/Microsoft 계열 Email, Calendar, Contacts, Drive, SharePoint, Teams 등 추가 연결 또는 건너뛰기.
5. 알림 허용 또는 나중에 설정.
6. 생성·스킬 준비·플러그인 준비·마무리 진행 상태.
7. 소개 대화와 메시지 화면으로 연결.

계정 변경, 관리자 제한, 워크스페이스 자격, 지역/좌석 조건, 준비 실패와 결과 불명확 상태를 처리한다. 번들에 Business Premium 등의 문구가 있지만 이는 분기 존재의 증거이지 현재 플랜 정책을 검증한 자료가 아니다. [E17–E19]

온보딩 링 애니메이션에는 grow 650ms, hole 400ms, flight 650ms, long flight 1050ms, reveal 800ms 등의 상수가 있다. 화면 이동에 `departing`·`flying`·`arrived` 상태를 사용하며 모션 감소 조건과 리사이즈·가시성 변경 처리도 있다. [E20 및 dot-onboarding-flight]

마스코트 버튼에는 `idle`, `running`, `waving`, `jumping`을 사용하는 분기와 notification badge, hover/tap/pointer 관련 처리가 있다. 이 공용 마스코트 컴포넌트를 특정 dot의 유일한 렌더러로 단정하지 않는다. [E21]

## OhMyDots 구현에 적용할 때의 판단

기존 `docs/DOTS-UI.md`의 프로필·대화·컴퓨터·결과물 분리는 이번 배포 코드와 비교할 수 있는 출발점이다. 이번 작업에서는 애플리케이션 코드를 수정하지 않았다.

| 우선 검토할 부분 | 적용 방향 |
| --- | --- |
| dot 식별 | 프로필 ID, 표시 이름, 현재 루트 작업 ID, 메시지 방 ID를 별도 모델로 취급 |
| 외형 | 편집 초안과 저장 결과를 분리하고 이름·아바타·대화 accent를 함께 반영 |
| 메시지 | 로컬 저장, 업로드, 전송, 전달 미확인, 읽음, 재시도를 구분 |
| 상태 | 작업 중·최근 활동·일시정지·입력 대기를 하나의 busy 표시로 합치지 않기 |
| 결과물 | 현재 dot/작업의 결과와 전체 파일 목록의 범위를 명확히 표시 |
| 설정 | 실제 지원 기능과 계정/환경 조건을 반영한 메뉴 구성 |
| 온보딩 | 건너뛰기·부분 연결·진행 복원·실패 복구·중복 생성 방지 |
| 접근성 | 아바타 접근성 이름, IME 조합 중 Enter 방지, 모션 감소, 키보드 탐색 |

## 확인 범위와 남은 항목

| 질문 | 상태 |
| --- | --- |
| 앱 셸과 채팅·설정·dot의 주요 구성 | 정적 모듈 및 문구로 확인 |
| 설정의 메뉴 후보와 조건부 표시 | 확인. 현재 계정의 실제 메뉴는 미확인 |
| dot 프로필·루트 작업·메시지 방 관계 | 정적 참조 확인. 실제 네트워크/저장 동작은 미검증 |
| 외형 편집, 색상, SVG, 애니메이션 상수 | 관련 코드에서 확인 |
| 베르데의 현재 이름·아바타·연결 상태 | 계정 프로필을 읽지 않아 미확인 |
| 실제 픽셀 배치, 전체 화면 스크린샷, 포커스 이동 | 앱 직접 UI 접근 제한으로 미확인 |
| 모든 화면과 기능 플래그 조합의 완전한 목록 | 부분적. 번들 전체의 모든 동적 경로를 추적한 결과는 아님 |

실제 화면과의 시각 비교는 사용자가 제공한 캡처를 근거로 추가할 수 있다. 정적 분석 결과를 현재 계정의 실행 화면처럼 제시하지 않는다.
