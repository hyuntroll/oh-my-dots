# Earlier local UI checkpoint — 2026-10-25

This branch records the existing uncommitted work in the original OhMyDots checkout before adopting the separately reconstructed original-client UI. It preserves the earlier web/desktop UI, native character integration, OpenCode and lifecycle changes, and the associated source evidence and screenshots. It is an archival checkpoint, not a new validation or deployment of those earlier changes.

The current original-client UI is developed separately in `dots-reconstructed` and recorded under `apps/dots-reconstructed/` on branch `codex/dots-original-ui`. That branch has its own setup instructions, original asset manifest, browser evidence and current verification results. Existing runtime databases, local environments, credentials and dependency/build caches are excluded from this checkpoint.
