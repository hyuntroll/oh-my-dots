# Dots character icons

`characters.png` is a transparent icon sprite reconstructed with image generation from the five promotional images supplied by the user. It is a derived asset, not an official standalone icon download.

The 1536 × 1024 PNG contains 512 × 512 cells: Iggy, Felipe, Todd in the first row; Alfred, Jojo, empty in the second. `DotAvatar` crops cells through SVG viewBox and preserves each character’s native palette. Character selection also sets a matching desktop theme color.
