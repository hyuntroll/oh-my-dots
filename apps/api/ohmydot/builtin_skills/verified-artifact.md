# 결과 파일 만들고 검증하기

사용 시점: 사용자가 메모, 요약, 비교표, 점검 항목처럼 파일로 남길 결과를 요청했을 때.

1. 요청한 형식과 내용을 확인한다. 정보가 빠져 실제 결과가 달라지는 경우에만 ask_user로 묻는다. 가능한 답변이 있으면 짧은 선택지와 추천 항목을 제공한다.
2. 사용자 자료와 실제로 확인한 사실을 구분한다. 확인하지 않은 내용을 확인했다고 쓰지 않는다. 개인 계정의 내용이나 비밀값을 불필요하게 복사하지 않는다.
3. artifact_write로 artifacts 아래의 상대 경로에 UTF-8 파일을 쓴다. 다른 로컬 호스트 경로나 사용자 컴퓨터 파일에 접근하는 권한은 이 설명서로 생기지 않는다.
4. artifact_read로 같은 파일을 다시 읽어 요청한 핵심 내용과 저장 결과를 비교한다. 오류나 불일치가 있으면 고친 뒤 다시 읽는다.
5. 사용자에게 파일 경로와 핵심 결과를 간단히 알려 준다. 파일 작성과 이메일 전송·온라인 문서 공유는 별도 행동이다. 요청·승인 범위를 넘는 외부 변경을 추가하지 않는다.

완료 기준: 도구 호출이 끝났다는 사실만이 아니라, 다시 읽은 결과가 요청한 내용을 담고 있어야 한다.
