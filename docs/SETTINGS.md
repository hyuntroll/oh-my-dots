# 설정 화면

실행 중인 Orca의 AI 제공자 계정 화면에서 확인한 왼쪽 탐색·설정 검색·제공자별 카드·상태 배지를 참고했습니다. OhMyDots가 실제 지원하는 Codex와 OpenAI API를 표시합니다.

- AI 연결: 연결 상태, 현재 사용 중인 제공자, Codex 로그인 및 OpenAI 키 입력. 기본 제공자 변경은 저장 후 적용됩니다.
- 에이전트: 기본 제공자와 모델. 탭을 이동해도 저장 전 입력이 유지되며 서버의 기존 실행 중 변경 제한을 따릅니다.
- 사용량: 모델이 보고한 제공자별 입력·출력·캐시 토큰. 계정 잔여 한도나 청구 금액은 표시하지 않습니다.
- 일반: Enter 또는 Cmd/Ctrl+Enter 전송, 다음 시작 시 컴퓨터 표시, 대화 UI의 애니메이션 줄이기. 브라우저 localStorage에 자동 저장하며 다른 탭에도 동기화됩니다. 운영체제의 모션 줄이기 설정도 존중합니다.
- 컴퓨터: 실제 연결·제어권·해상도와 상태 새로고침. 소유권을 자동 변경하지 않습니다.

설정은 키보드 포커스를 유지하는 전체 화면 대화상자이며 Escape 또는 대화로 돌아가기로 닫습니다. 검색은 메뉴 이름과 관련 키워드를 사용합니다. 좁은 화면에서는 상단 탐색으로 전환합니다.

## 검증

웹 테스트 13개와 TypeScript/production 빌드 통과. 잘못된 저장 데이터 복원, 한글 IME 조합 및 Shift+Enter 오전송 방지를 확인했습니다. 실제 브라우저에서 검색, 제공자 상태, 모델 초안 탭 이동 유지, 사용량, 컴퓨터 해상도와 제어 상태를 확인했습니다. 일반 설정 변경 후 Enter가 전송되지 않는 동작, 모션 설정의 DOM 반영, 새로고침 후 값 유지도 확인했습니다. 검증 값은 기존 기본값으로 복원했고 인증이나 모델 설정은 변경하지 않았습니다.
